SCS-C02 → SCS-C03 Changes

What changed in the new exam?

SCS-C03 launched December 2, 2025 with restructured domains, new AI/ML security content, and shifted weightings. This is not a cosmetic refresh.

Restructured

Domains Renamed & Split

"Threat Detection & IR" split into two dedicated domains: Detection (16%) and Incident Response (14%). "Security Logging & Monitoring" absorbed into IR. "Management & Governance" → "Security Foundations & Governance."

New Topics

Generative AI Security

Brand-new coverage of securing LLM/GenAI workloads: GenAI OWASP Top 10, Amazon Bedrock guardrails, Amazon Q, CodeGuru Security, and protecting model inference endpoints.

Reweighted

IAM Now the Biggest Domain

Identity & Access Management jumped from 16% → 20%, reflecting its central role in zero-trust architectures. Infrastructure Security dropped 20% → 18%.

Expanded

New Services In-Scope

Amazon Security Lake, AWS Verified Access, Automated Forensics Orchestrator for EC2, AWS Private CA, Network Access Analyzer, Route 53 Resolver DNS Firewall, IAM Roles Anywhere, Amazon Verified Permissions.

Updated

Governance Expanded

SCPs now joined by Resource Control Policies (RCPs) and declarative policies. Centralized root access management for member accounts. AWS Fault Injection Service for IR testing.

Hybrid

Hybrid & Multi-Cloud

Explicit coverage of hybrid connectivity security: Site-to-Site VPN with MACsec, Direct Connect encryption, and AWS Verified Access for zero-trust application access without a VPN.

Difficulty Breakdown

How hard is SCS-C03, really?

Questions span three cognitive levels. The Advanced tier demands multi-service scenario reasoning — especially now with AI/ML and hybrid workloads added to the mix.

Foundational

Service Identification

Recall which AWS service solves a specific security problem. Fastest to answer; reward broad AWS familiarity. Now includes new C03 services.

  • Which service detects port scans on EC2 instances?
  • How do you store database credentials securely?
  • What centralises security findings across accounts?
  • Which service classifies sensitive PII in S3?
~30% of exam
Intermediate

Configuration & Design

Apply services correctly under scenario constraints. Know the difference between SCPs vs RCPs vs permission boundaries, or when to use Verified Access vs VPN.

  • Configure least-privilege for a cross-account Lambda role
  • Block all public S3 regardless of bucket policies (org-wide)
  • Design zero-trust access to internal apps without VPN
  • Protect a Bedrock model endpoint from prompt injection
~38% of exam
Advanced

Troubleshoot & Architect

Diagnose why a security control is failing under complex conditions, or design a full solution across IAM, encryption, network, and logging layers simultaneously.

  • SCP deny not blocking resource creation — find the root cause
  • Design a zero-trust data pipeline for regulated PII at scale
  • Detect and contain a compromised IAM key in real-time
  • Architect secure multi-account GuardDuty with auto-remediation
~32% of exam

Least Privilege

Grant only permissions actually needed. Applies to IAM, SCPs, RCPs, bucket policies, and VPC security groups. IAM Access Analyzer can flag overly permissive policies.

Exam Strategy

Nine tactics that move the needle

SCS-C03 adds new services to know but the core test-taking instincts are the same. Pattern recognition is as critical as raw knowledge.

01

Always pick the most managed option

AWS exam logic favours AWS-native managed services. If GuardDuty exists, don't design a custom log analysis Lambda unless the scenario forces it.

02

Follow the "least privilege" instinct

When two answers look similar, pick the one with narrower permissions. In C03, also ask: should this be an SCP (prevents action) or an RCP (controls resource access)?

03

Explicit Deny wins everything

An explicit Deny overrides any Allow regardless of source — IAM, SCP, RCP, resource-based, or session policy. This appears in 8–12 questions across IAM and governance domains.

04

IAM is now 20% — invest accordingly

With IAM as the largest domain, spend extra time on Access Analyzer findings, ABAC tag conditions, Roles Anywhere trust anchors, and Verified Permissions policy languages.

05

Read the constraint, not just the scenario

"Operationally efficient," "without additional cost," and "without modifying application code" are constraints that eliminate otherwise correct answers. Spot them first.

06

Know Security Lake vs CloudTrail Lake

Security Lake centralises logs in OCSF format for third-party SIEM integration. CloudTrail Lake stores and queries CloudTrail events using SQL. Different use cases — frequent distractor pair.

07

Multi-response: eliminate first

For "select TWO" questions, eliminate the clearly wrong answers. Then compare survivors — usually one pair fits best together. Partial credit is NOT awarded for wrong answer selections.

08

Time: ~2.5 min per question

170 minutes / 65 questions = 2.6 min each. Flag anything over 3 minutes and keep moving. Unanswered = 0 points. Wrong guesses have no additional penalty.

09

Use AWS Skill Builder's official C03 prep

The official SCS-C03 exam prep plan on AWS Skill Builder maps 1:1 to the current exam domain structure. Aim for consistent 78%+ before booking. The older SCS-C02 practice sets are still useful but watch for stale domain names.
