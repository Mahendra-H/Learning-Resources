SDK + Architecture
Works alongside your existing stack · No rip-and-replace · Open source · Self-hostable
Observer · Decorator · Pub/Sub · Repository · Strategy · Chain of Responsibility · Facade · Event Sourcing

Argus does not replace Vault, Keycloak, Ory, or Authentik. It is a neutral orchestration bridge — connecting the behavioural anomaly signal to a coordinated security response across all four tools simultaneously.

Design patterns
Observer + Decorator (SDK)
Wraps any agent without modifying it. Intercepts every call transparently. Emits to Redis Streams every 30s.
Chain of Responsibility (Policy)
Anomaly passes through severity handlers — LOW logs, MEDIUM alerts, HIGH responds, CRITICAL pauses for human approval.
Strategy + Facade (Response)
Each tool action is a Strategy. Each tool's REST API hidden behind a clean Facade. Swappable without changing the orchestrator.
Event Sourcing (Audit)
Append-only PostgreSQL. Every state change is an immutable event. No UPDATEs. Full replay and forensic investigation.
