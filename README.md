# Learning-Resource

Personal learning library organized by **technology domain** (not foundations vs courses).

## How to browse

1. Open a **tech folder**: `ai` / `iam` / `cloud` / `security` / `devops`
2. Open the **series** folder
3. Start with the index / module 1 / page 0 file

## Top-level map

| Folder | What belongs here |
|---|---|
| `ai/` | LLM, RAG, agents, coding tools, SDD, Outskill |
| `iam/` | Auth, OAuth, SAML, Entra, Ping, IAM architect |
| `cloud/` | AWS (and future cloud platform certs) |
| `security/` | CISSP, cyber org / security leadership |
| `devops/` | GitHub Actions, Ansible, Terraform |
| `projects/` | POCs and applied architecture work |
| `templates/` | HTML themes, prompts, skills |
| `reference/` | Links, migrations, research notes |
| `archived/` | Retired material |

## Naming convention

- Tech roots: short lowercase (`ai`, `iam`, `cloud`, `security`, `devops`)
- Series folders: kebab-case
- Ordered modules: optional `NN-` prefix
- No spaces or emoji in folder names
- File names stay as-is
