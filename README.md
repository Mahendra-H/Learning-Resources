# Learning-Resource

Personal learning library of course modules, notes, POCs, and reference material.

## How to browse

1. Pick a **stage**: foundations → courses → projects  
2. Pick a **domain**: `ai` / `iam` / `infrastructure` / `security`  
3. Open the course folder and start with its index / module 1 file  

## Folder map

| Stage | Path | Purpose |
|---|---|---|
| Foundations | `01-foundations/` | Core series and fundamentals |
| Courses | `02-courses/` | Multi-module mastery tracks |
| Projects | `03-projects/` | POCs and architecture notes |
| Templates | `04-templates/` | HTML themes, prompts, skills |
| Reference | `05-reference/` | Links, migrations, research |
| Archived | `06-archived/` | Retired material |
