05 — Accordion

The 5 Worst Credit Mistakes

Expand each one for the root cause and the exact fix. These five alone account for 80%+ of unexpected credit drain across enterprise teams.

WHY IT DRAINS CREDITS
You switched to Claude Sonnet for a real security review at 11am. You got your answer. But the model selector stayed on Sonnet. For the rest of the day — every "what does this variable do?", every quick test question, every boilerplate generation — Sonnet was billing you at $3/$15 per million tokens for work that GPT-4.1 handles for free. One forgotten model switch costs 50–150 credits per day of ambient use.
THE EXACT FIX
Make switching back a muscle memory ritual. The moment you get your premium model response, immediately click the model selector and switch to GPT-4.1. No exceptions. Some teams put a sticky note on their monitor: SWITCH BACK AFTER EVERY PREMIUM TASK. It sounds silly. It works.
WHY IT DRAINS CREDITS
Copilot Code Review now has a dual billing model: it costs AI Credits for token usage AND GitHub Actions minutes simultaneously. Enabling it on every branch push means a developer who pushes 8 times per day on a feature branch triggers 8 reviews — each one burning credits + Actions minutes, even for trivial WIP commits. A busy team of 10 can drain 500+ credits per day from CI review alone, invisibly.
THE EXACT FIX
Enterprise admins: restrict the Code Review policy to main and release/* branches only. Disable it entirely on feature branches. Developers: trigger code review manually, once, on the final PR before merge — not on every push. The GitHub org policy Allow Copilot code review on PR should require explicit trigger, not auto-run on push.
WHY IT DRAINS CREDITS
Typing @workspace why is the SAML flow failing? in a monorepo with 400+ files instructs Copilot to semantically index and scan the entire repository to find relevant context before answering. This can push 50,000–100,000+ input tokens before you've received a single word of output. Input tokens on premium models at $3–$15/M add up fast. Many developers don't realize @workspace is a full-repo scan trigger.
THE EXACT FIX
Always scope your references explicitly. Use @file AuthService.java instead of @workspace when you know which file is relevant. For monorepos, always specify the module or file path: "In the auth-service module, specifically AuthnRequestBuilder.java...". If you must use @workspace, add .copilotignore to exclude vendor/, node_modules/, generated/, and test fixtures.
WHY IT DRAINS CREDITS
"Refactor the user management module" sent to Copilot Coding Agent causes the agent to first explore the repository to understand what's in the module, read every related file, plan its approach, then execute — all before changing a line of code. That exploration phase alone can consume 20,000–50,000 input tokens on a medium codebase. Then the multi-turn execution compounds on top. Reports of 150-credit single sessions are almost always from under-scoped agent tasks.
THE EXACT FIX
Before you launch any agent: write down 1) the exact list of files to touch, 2) the specific goal in one sentence, 3) the acceptance criteria in 2–3 bullet points. Paste this as the agent's first message. This eliminates the exploration phase entirely. If you can't fill in those three things in under 5 minutes, you don't have enough clarity to run the agent yet — do that thinking yourself first.
WHY IT DRAINS CREDITS
You ask Claude Sonnet a question. The answer isn't quite right. You follow up: "Actually, also include X." It's still not right. "Can you make it more concise?" Then: "Wait, the format is wrong, can you redo it as..." Each turn re-sends the entire conversation history as input, plus generates new output. A 5-turn conversation on Sonnet costs 5× what a single well-scoped question costs — often more, since context grows with each turn.
THE EXACT FIX
If the first answer was wrong, close the chat and fix your prompt — don't follow up in the same thread. Ask yourself: did I specify the output format? Did I constrain the scope? Did I give enough (but not too much) context? Rewrite the prompt with those fixes and open a fresh chat. One improved prompt beats five follow-up turns every time, both for quality and for credit cost.
