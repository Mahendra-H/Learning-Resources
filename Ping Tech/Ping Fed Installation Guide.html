00intro

Overview & Architecture

What this Ansible project automates and the target deployment topology.

This guide walks through a production-ready Ansible role and playbook structure for installing and configuring PingFederate in clustered mode — one Admin node plus N Engine nodes. The automation handles every step from OS hardening through service verification, and is designed to be fully idempotent and environment-aware (dev/staging/prod, on-prem/AWS).

What the Ansible Automation Covers

OS Preparation

User/group creation, directory layout, OS limits (ulimit), firewall rules, SELinux/AppArmor adjustments, NTP configuration.

Java 17 Install

Install OpenJDK 17 from package repo or custom path. Set JAVA_HOME, validate version. Optionally install Amazon Corretto on AWS.

PingFederate Deploy

Download/copy the ZIP, extract to target path, install license, configure run.properties and tcp.xml per node role (admin vs engine).

Cluster Config

Configure JGroups TCP discovery (S3_PING for AWS, TCPPING for on-prem), set operational mode per host group, configure engine→admin connectivity.

Systemd Service

Install a systemd unit file for PingFederate, enable on boot, configure restart policy and JVM options via environment file.

Post-Install Verify

Wait for PingFederate to come up, hit the heartbeat endpoint, validate the cluster member count, assert no errors in server.log.

Target Topology

🏗
Deployment Model The Ansible inventory defines two host groups: [pf_admin] (exactly one node) and [pf_engines] (one or more nodes). The Admin node runs in CLUSTERED_CONSOLE mode and is never added to the load balancer target group. Engine nodes run in CLUSTERED_ENGINE mode and are behind the LB. Both groups run the same role with behavior controlled by host-group-specific variables.
Host GroupPF ModePortsIn LB?Startup Dependency
pf_adminCLUSTERED_CONSOLE9999 (admin), 7600 (JGroups)NoStarts first — engines wait for it
pf_enginesCLUSTERED_ENGINE9031 (runtime), 7600 (JGroups)YesRequires admin to be up and cluster formed

ansible --version
# Requires: ansible-core >= 2.14  (for community.general + ansible.posix)

# ── 2. Install required collections
ansible-galaxy collection install \
  community.general \
  ansible.posix \
  amazon.aws          # only needed for AWS dynamic inventory

# ── 3. Python dependencies on control node
pip3 install boto3 botocore   # for AWS dynamic inventory plugin

# ── 4. SSH key setup — control node must reach all targets
ssh-keygen -t ed25519 -C "ansible-pingfederate"
# Copy public key to all target hosts:
ssh-copy-id -i ~/.ssh/ansible_pf.pub pf-admin01.example.com
ssh-copy-id -i ~/.ssh/ansible_pf.pub pf-engine01.example.com
ssh-copy-id -i ~/.ssh/ansible_pf.pub pf-engine02.example.com

# ── 5. Test connectivity
ansible -i inventory/prod/hosts.yml all -m ping \
  --private-key ~/.ssh/ansible_pf
# Expected: pong from all hosts

Every task file in the pingfederate role, from OS preparation through post-install verification.

roles/common/tasks/main.yml — OS Preparation

yamlroles/common/tasks/main.yml
---
# Common OS preparation tasks applied to ALL PingFederate hosts

- name: Create pingfederate OS group
  ansible.builtin.group:
    name: "{{ pf_group }}"
    gid: "{{ pf_user_gid }}"
    state: present
  tags: [user, setup]

- name: Create pingfederate OS user
  ansible.builtin.user:
    name: "{{ pf_user }}"
    uid: "{{ pf_user_uid }}"
    group: "{{ pf_group }}"
    shell: /sbin/nologin
    home: "{{ pf_install_dir }}"
    create_home: false
    system: true
    comment: "PingFederate Service Account"
    state: present
  tags: [user, setup]

- name: Create base installation directory
  ansible.builtin.file:
    path: "{{ pf_install_dir }}"
    state: directory
    owner: "{{ pf_user }}"
    group: "{{ pf_group }}"
    mode: '0750'
  tags: [setup]

- name: Set OS file descriptor limits for pingfederate user
  community.general.pam_limits:
    domain: "{{ pf_user }}"
    limit_type: "{{ item.type }}"
    limit_item: "{{ item.item }}"
    value: "{{ item.value }}"
  loop:
    - { type: soft, item: nofile, value: "{{ pf_nofile_limit }}" }
    - { type: hard, item: nofile, value: "{{ pf_nofile_limit }}" }
    - { type: soft, item: nproc,  value: "{{ pf_nproc_limit }}" }
    - { type: hard, item: nproc,  value: "{{ pf_nproc_limit }}" }
  tags: [limits, setup]

- name: Configure NTP (chrony)
  ansible.builtin.package:
    name: chrony
    state: present
  tags: [ntp]

- name: Enable and start chronyd
  ansible.builtin.service:
    name: chronyd
    state: started
    enabled: true
  tags: [ntp]

- name: Open firewall ports (when pf_manage_firewall is true)
  ansible.posix.firewalld:
    port: "{{ item }}"
    zone: "{{ pf_firewall_zone }}"
    permanent: true
    state: enabled
  loop:
    - "{{ pf_https_port }}/tcp"
    - "{{ pf_cluster_port }}/tcp"
    - "{{ pf_cluster_failure_detection_port }}/tcp"
  when: pf_manage_firewall | bool
  notify: reload firewalld
  tags: [firewall]

- name: Open admin port (admin hosts only)
  ansible.posix.firewalld:
    port: "{{ pf_admin_port }}/tcp"
    zone: "{{ pf_firewall_zone }}"
    permanent: true
    state: enabled
  when: pf_manage_firewall | bool and pf_operational_mode == "CLUSTERED_CONSOLE"
  notify: reload firewalld
  tags: [firewall]

roles/pingfederate/tasks/install.yml

yamlroles/pingfederate/tasks/install.yml — Extract, License, Permissions
---
# install.yml — Download/copy and extract PingFederate

- name: Create temp extraction directory
  ansible.builtin.file:
    path: "{{ pf_tmp_dir }}"
    state: directory
    mode: '0755'
  tags: [install]

# ── Option A: copy local ZIP from files/ directory
- name: Copy PingFederate ZIP from control node (local source)
  ansible.builtin.copy:
    src: "{{ pf_zip_filename }}"
    dest: "{{ pf_tmp_dir }}/{{ pf_zip_filename }}"
    owner: "{{ pf_user }}"
    group: "{{ pf_group }}"
    mode: '0640'
    checksum: "{{ pf_checksum | default(omit) }}"
  when: pf_source == "local"
  tags: [install]

# ── Option B: download from artifact server / S3
- name: Download PingFederate ZIP from URL
  ansible.builtin.get_url:
    url: "{{ pf_download_url }}"
    dest: "{{ pf_tmp_dir }}/{{ pf_zip_filename }}"
    checksum: "{{ pf_checksum | default(omit) }}"
    owner: "{{ pf_user }}"
    group: "{{ pf_group }}"
    mode: '0640'
  when: pf_source == "url"
  tags: [install]

- name: Download PingFederate ZIP from S3
  amazon.aws.s3_object:
    bucket: "{{ pf_s3_bucket }}"
    object: "{{ pf_s3_key }}"
    dest: "{{ pf_tmp_dir }}/{{ pf_zip_filename }}"
    mode: get
  when: pf_source == "s3"
  tags: [install]

- name: Check if PingFederate is already extracted (idempotency guard)
  ansible.builtin.stat:
    path: "{{ pf_home }}/bin/run.sh"
  register: pf_extracted

- name: Extract PingFederate ZIP
  ansible.builtin.unarchive:
    src: "{{ pf_tmp_dir }}/{{ pf_zip_filename }}"
    dest: "{{ pf_install_dir }}"
    remote_src: true
    owner: "{{ pf_user }}"
    group: "{{ pf_group }}"
    creates: "{{ pf_home }}/bin/run.sh"   # idempotent: skip if already exists
  tags: [install]

- name: Set ownership on entire PF directory tree
  ansible.builtin.file:
    path: "{{ pf_home }}"
    owner: "{{ pf_user }}"
    group: "{{ pf_group }}"
    recurse: true
  tags: [install, permissions]

- name: Install PingFederate license file
  ansible.builtin.copy:
    src: pingfederate.lic
    dest: "{{ pf_conf_dir }}/pingfederate.lic"
    owner: "{{ pf_user }}"
    group: "{{ pf_group }}"
    mode: '0640'
  tags: [install, license]

- name: Make run.sh executable
  ansible.builtin.file:
    path: "{{ pf_home }}/bin/run.sh"
    mode: '0750'
  tags: [install]

- name: Copy plugin JARs to deploy directory
  ansible.builtin.copy:
    src: "plugins/{{ item }}"
    dest: "{{ pf_deploy_dir }}/{{ item }}"
    owner: "{{ pf_user }}"
    group: "{{ pf_group }}"
    mode: '0640'
  loop: "{{ pf_plugins }}"
  when: pf_plugins | length > 0
  tags: [install, plugins]

- name: Clean up temp directory
  ansible.builtin.file:
    path: "{{ pf_tmp_dir }}"
    state: absent
  tags: [install, cleanup]

# configure.yml — Deploy all configuration files via Jinja2 templates

    group: "{{ pf_group }}"

    dest: "/etc/default/pingfederate"
    owner: root
    group: root

  notify: restart pingfederate
  tags: [configure, jvm]

- name: Ensure log directory exists with correct permissions

    path: "{{ pf_log_dir }}"

Rolling Upgrade Playbook

yamlupgrade.yml — Zero-Downtime Rolling Engine Upgrade
---
# upgrade.yml — Rolling upgrade of engine nodes with zero downtime
# Prerequisites:
#   1. Set pf_version to the NEW version in group_vars
#   2. Place the new ZIP in roles/pingfederate/files/
#   3. Admin node must already be upgraded and running
# Run: ansible-playbook upgrade.yml --ask-vault-pass -e pf_version=12.1.1

- name: Rolling upgrade of PingFederate engine nodes
  hosts: pf_engines
  gather_facts: true
  serial: 1                   # upgrade one engine at a time for zero downtime
  max_fail_percentage: 0       # abort entire play if any engine fails

  tasks:
    - name: Remove engine from load balancer (if LB managed by Ansible)
      ansible.builtin.debug:
        msg: "Draining {{ inventory_hostname }} from LB — implement per your LB type"
      # Example for AWS ALB: use community.aws.elb_target module
      # Example for HAProxy: community.general.haproxy module
      tags: [upgrade, drain]

    - name: Wait for in-flight requests to drain (grace period)
      ansible.builtin.pause:
        seconds: 30
      tags: [upgrade, drain]

    - name: Stop PingFederate service
      ansible.builtin.service:
        name: pingfederate
        state: stopped
      tags: [upgrade]

    - name: Backup current PF installation
      ansible.builtin.archive:
        path: "{{ pf_home }}"
        dest: "{{ pf_install_dir }}/pingfederate-{{ pf_version }}.BACKUP.tar.gz"
        format: gz
      tags: [upgrade, backup]

    - name: Install new PingFederate version
      ansible.builtin.include_role:
        name: pingfederate
        tasks_from: install
      tags: [upgrade]

    - name: Apply configuration templates (new version may have new config keys)
      ansible.builtin.include_role:
        name: pingfederate
        tasks_from: configure
      tags: [upgrade]

    - name: Start PingFederate service
      ansible.builtin.service:
        name: pingfederate
        state: started
      tags: [upgrade]

    - name: Wait for engine to come up and join cluster
      ansible.builtin.uri:
        url: "https://{{ ansible_host }}:{{ pf_https_port }}/pf/heartbeat.ping"
        validate_certs: false
        status_code: 200
      register: hb
      until: hb.status == 200
      retries: 20
      delay: 10
      tags: [upgrade, verify]

    - name: Re-add engine to load balancer
      ansible.builtin.debug:
        msg: "Returning {{ inventory_hostname }} to LB pool"
      tags: [upgrade, drain]

    - name: Wait between engines (let traffic stabilize)
      ansible.builtin.pause:
        seconds: 15
      tags: [upgrade]

Idempotency Design

♻
Every task is safe to re-run The role uses Ansible's built-in idempotency mechanisms throughout. The unarchive module uses creates: so extraction is skipped if already done. The copy and template modules only trigger the restart handler when the file content actually changes. Re-running the playbook on a healthy cluster makes zero changes and does not restart PingFederate.
Pattern UsedTaskIdempotency Mechanism
creates:Extract ZIPSkip extraction if run.sh already exists
state: presentUser/group/packageModule checks existence before creating
changed_when: falseVersion check, log scanRead-only tasks never report changed
notify + handlerConfig file changesRestart only fires if file content changed
stat + whenConditional tasksSkip tasks whose outcome already matches desired state
lineinfile regexp:JAVA_HOME in /etc/environmentReplace existing line rather than appending
